## What shipped

- **Allocate screen** (`/wealth/allocate`) — surplus starts as today’s free-to-allocate. Pencil → override amount + reason (reason required when it differs from free). “Why this number?” shows the same Home breakdown.
- **Waterfall preview** — three rows with after-fill caption, fill-mode label, editable amount (re-flows leftover). **Reset to plan** clears overrides.
- **SIP / dip preview** when Investment > 0 — SIP pool, dip credit, per-asset SIP rupees. Read-only; the plan editor is Phase 21.
- **Confirm** — pick From → To per positive line (e.g. HDFC Savings → FD). One SQLite transaction writes Transfer/Investment ledger rows (`source=allocation`, category Investment, not in budget) plus the run. All land or none.
- **History** — past proposed/confirmed runs. Confirmed runs are not rewritten (409); a later allocate is a new run (amendments = new ledger rows).
- **Negative free cash** — Home and Wealth hide/disable Allocate with **Committed beyond liquid**, same as Home.
