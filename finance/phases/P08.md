## What shipped

Pure TypeScript in `app/src/engine/`. No IndexedDB, no React. The phone UI is unchanged from Phase 1.

- **`splitInvest(amount, plan)`** — SIP pool, dip credit, active assets (core ∪ allowed themes), normalised weights, rupee rounding remainder → largest weight
- **`seedDefaultInvestPlan()`** — 70/30, Gold omitted, theme engine below ₹20,000 → AI Infrastructure only
- **`inactivateGold(plan)`** — if a Gold row is present, `active=false` so the rest re-normalise
- **`validateInvestPlan`** — SIP + dip = 10_000 bp; at most one unbounded theme tier
- **`resolveThemeTier`** — first matching `belowAmount` (unbounded last); ₹20,000 exactly uses the top tier
- **`goalAffordability`** — funded, remaining, available_now, status pills from architecture §5.10 / UX §3.6.4
- **`monthsBetween`** — calendar-month difference of YYYY-MM (day ignored)

Formulas match architecture §5.9–5.10:

```
sip_pool         = amount × sip_bp / 10000
dip_credit       = amount − sip_pool
active_assets    = active cores ∪ allowed themes for this amount
weights          = normalise(target_bp over active_assets)
sip_order[asset] = sip_pool × weight   // rounded to ₹1, remainder → largest weight
```

```
funded        = Σ contributions
remaining     = target − funded
available_now = bucket balance − Σ remaining of higher-priority active goals on that bucket
status        = achieved | affordable now | on track | behind | saving
```

- Amount 0 or negative → SIP/dip/orders are ₹0, no throw. Leftover keeps the (possibly negative) amount.
- Percent is of the **original** monthly invest amount. Dip credit is the remainder so SIP + dip always equals the amount.
- Theme filter is on the **split amount**. Below ₹20,000 only AI Infrastructure among themes; cores still get their share. Other themes ₹0.
- Gold is not in the default seed. If present and inactivated, it takes ₹0 and cores + allowed themes re-normalise.
- `available_now` can be less than remaining (honest). Paused / dropped goals do not reserve cash.
- `expected_monthly_into_bucket` is an input (last allocation run). Missing → 0.
