# Phase 11 — Seed investment side (approved)

Implemented 2026-09-06. Product checkbox in `plan.md` stays unticked until you approve.

## What shipped

Finance-Mng is already in SQLite (Phase 10). This phase adds **invest / goal tables**, **tags FD / ICICI Savings / Mutual Fund onto the three buckets**, and a **seed wizard** on `/dev/engine`. Wealth is still a Phase 18 placeholder.

- **Migration `0002_invest`** — `invest_plans`, `invest_assets`, `invest_theme_tiers`, `goals`, `goal_contributions`. Schema version **3**. Existing `data/finance.sqlite` migrates on next API start; ledger rows stay.
- **Account → bucket** — FD → Emergency Fund, ICICI Savings → Savings buffer, Mutual Fund → Investment. HDFC Savings / Cash / Wallet stay unassigned liquid. Finance re-import also applies this map.
- **`POST /api/import/invest`** — multipart xlsx (`Config` + `Goal Fund` + `Investing`). One transaction. Gold is imported **inactive**. Goal names come in; rupee targets stay blank (MacBook / iPhone and the % allocations are not rupee targets). Hard cash ₹10,000 becomes the Savings buffer target.
- **`POST /api/seed/invest`** — default 70/30 plan, no Gold, theme engine below ₹20,000 → AI Infrastructure only.
- **`PUT /api/seed/invest`** — persist Savings target, EF months, SIP/dip %. Survives API restart.
- **`GET /api/engine-summary`** — bucket current vs target, tagged accounts, confirmation line, plan, goals.
- **`/dev/engine`** — seed wizard + that summary. `/dev/store` links here.

Does **not** write either Excel file. Does **not** open Wealth.
