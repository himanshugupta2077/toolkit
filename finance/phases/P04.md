# Phase 4 — Budget pace + month summary (done, awaiting your review)

Implemented 2026-09-06. Product checkbox in `plan.md` stays unticked until you approve.

## What shipped

Pure TypeScript in `app/src/engine/`. No IndexedDB, no React. The phone UI is unchanged from Phase 1.

- **`budgetPace(month, entries, cap, today)`** — cap, spent, remaining, used %, elapsed %, days left, safe/day, pace band
- **`monthSummary(month, entries, categories)`** — income, budget spent, non-budget exp, investments, EMIs, rent, CC payments, est. savings
- **`resolveBudgetCap`** — that month's cap row, else the default cap

Formulas match architecture §5.2–5.3 and the Monthly Budget sheet:

- Spent = in-budget **expenses minus in-budget refunds** (sheet B8). Architecture §5.2 only wrote expenses; the live sheet nets refunds, so the engine does too.
- Remaining = cap − spent. Empty month → remaining = cap, not an error.
- Days left include today. Safe/day = `max(0, remaining) / daysLeft`, floored to paise.
- Used % = spent / cap (0 when cap is 0, same as `IF(B6=0,0,B8/B6)`).
- Elapsed % = day_of_month / days_in_month.
- Pace: used % ≤ elapsed % → `on_track`; within +10pp → `watch`; else `over`.
- Est. savings = income − budget spent − non-budget exp − investments. Rent and EMIs are listed separately and are **not** subtracted again.

A past month is fully elapsed (days left 0). A future month has elapsed 0 and a full month of days left.
