## What shipped

Pure TypeScript in `app/src/engine/`. No IndexedDB, no React. The phone UI is unchanged from Phase 1.

- **Bucket model** — priority, target rule (`fixed` | `months_of_essentials` | `none`), fill mode (`until_target` | `percent` | `fixed` | `remainder`)
- **`seedDefaultBuckets()`** — Emergency Fund → Savings buffer → Investment
- **`runWaterfall(surplus, buckets, currentBalances, essentialsAverage?)`**
- **`validateBuckets`** — exactly one active remainder; active % fills sum ≤ 100
- **`resolveBucketTarget` / `trailingEssentialsAverage` / `monthEssentials`** — EF target = 6 × trailing completed-month essentials
- **`bucketCurrentBalances`** — Σ of accounts tagged to a bucket

Formula matches architecture §5.8:

```
for bucket in active, ordered by priority:
    room = target ? max(0, target − current) : unbounded
    want = until_target ? room
         : percent      ? original_surplus × fill%
         : fixed        ? fill_value
         : remainder    ? remaining surplus
    give = min(want, room, remaining)
```

- Surplus 0 or negative → every line is ₹0, no throw. Leftover keeps the (possibly negative) surplus.
- Percent is of the **original** surplus, then capped by room and whatever is left.
- Lifestyle-style double-count: rent and EMIs are added once even if those categories are also marked essential.
- Trailing essentials uses **completed** months only, up to 3. Until 3 exist, it uses the months we have.
- `minMonthly` is stored on the bucket type for Phase 18; the waterfall does not apply it.
