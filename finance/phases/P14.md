## What shipped

More → **Accounts** is a real grouped list over SQLite. You still cannot type a live balance; the only writes are account metadata and, on a gap, an Adjustment ledger row.

- **More** — Accounts is live. Categories / Settings stay Phase 17 placeholders.
- **Grouped list** — Savings · Cash · Credit card · FD · Investment · (Loan / Other if present) · Virtual (collapsed). Row: name, calculated balance or Due, NW / Liquid flags, last reconciled (`21 d ago` amber if never or > 14 days).
- **Account detail** — calculated hero, opening (read-only), CC limit / available / utilisation, this-cycle spend (`statement_day` or calendar month), Reconcile, Edit, Archive (virtual accounts cannot be archived). Ledger list for this account; **Open in Ledger** uses the existing filter.
- **Add / edit** — name, group (type follows the group), opening only when adding, liquid / net-worth flags, optional bucket, CC limit + statement/due day. Archive if it has history — never delete.
- **Reconcile** (`/more/accounts/:id/reconcile`) — Calculated · Actual (keypad, prefilled with calculated when ≥ 0) · live Difference.
  - Difference 0 → **Mark reconciled today** (`POST /api/reconcile`, resolution `none`).
  - Difference ≠ 0 → **Find missing transaction** (Ledger filtered to this account, amount as search) or **Add adjustment** (note required). One SQLite transaction writes the Adjustment (External ↔ account, category Reconciliation, in-budget off) and the recon row. The gap closes.

`GET /api/accounts` and `GET /api/accounts/balances` return calculated balances + liquid. `POST /api/accounts`, `PATCH /api/accounts/:id`, `POST /api/reconcile`. Home is still a placeholder; `/dev/store` now shows **liquid** from the same engine number Home will use.

Out of scope as planned: swipe, Home pace card (Phase 15), categories/settings (Phase 17), writing either Excel file, IndexedDB.
