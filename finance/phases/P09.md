# Phase 9 — Server + SQLite store (approved)

Implemented 2026-09-06. Approved 2026-09-06 after `/dev/store` dummy spend survived an API restart (SQLite on the laptop).

## What shipped

Hono + SQLite on the laptop. The engine is unchanged (same functions). Product tabs are still Phase 1 placeholders. The new surface is a **dev store page** and `/api`.

- **`server/`** — Hono app on **8787** (`127.0.0.1`). Serves `/api/*`. In production (`npm start`) also serves `dist/`.
- **`npm run dev`** — Vite **5173** + API **8787** together. Vite proxies `/api` → `http://127.0.0.1:8787`.
- **Drizzle schema + first migration** — accounts, categories, settings, ledger_entries (soft delete), month_budgets, recurring_plans, one_time_plans, expected_inflows, buckets, meta. WAL + foreign keys on.
- **`loadBooks(db, today)`** — returns the engine `Books` snapshot (non-deleted ledger rows).
- **API:** `GET /api/health`, `GET /api/books`, `POST /api/ledger` (runs `validateLedgerEntry`), `GET /api/month/:yyyymm`, `GET /api/export.sqlite`.
- **Backup:** `npm run db:backup` → `VACUUM INTO data/backups/finance-….sqlite`. Also on server start if the last backup is older than 24 h.
- **Dev page `/dev/store`:** counts, this-month budget spent, **Add one dummy expense**, **Wipe** (red; button stays disabled until you type `wipe`).
- **`src/api/`** — thin `fetch` helpers the store page uses (TanStack Query on that page only).
- Empty Phase 1 `src/store/` is gone.

Empty databases get a **tiny seed catalog** (not your Excel): HDFC Savings, Expense / Employer / External, Groceries / Rent / EMIs / Investment / Reconciliation, default buckets, settings cap ₹31,000 / salary ₹1,40,000. Dummy expense is ₹100 Groceries, in-budget, from HDFC → Expense, dated **today IST**. Wipe deletes everything and re-seeds that catalog so the page still works.

Dev file: `app/data/finance.sqlite` (gitignored). Production path later: `~/finance-data/finance.sqlite`.

## What you should try before approving

1. `npm run dev` → `/dev/store` → **Add one dummy expense**. Counts.ledger goes 0 → 1. This month’s budget spent becomes ₹100.00.
2. Restart the API (Ctrl-C the `npm run dev` terminal, start it again). Clear site data in the browser. Open `/dev/store` — the dummy row is still there (`finance.sqlite` on the laptop, not the phone).
3. `GET /api/month/2026-09` (or the month of “today” if you are not in September) — `summary.budgetSpent` matches the dummy (₹100.00 = 10000 paise). From the phone over Tailscale, same URL path on the HTTPS host.
4. `npm run db:backup` — a file appears under `app/data/backups/`. `sqlite3` on that file shows the dummy row.
5. Wipe: typing anything except `wipe` keeps the button disabled / API returns 400. Typing `wipe` clears the ledger and puts the seed catalog back.
