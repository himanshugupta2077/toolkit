# Phase 1 — App shell (done, awaiting your review)

Implemented 2026-09-06. Product checkbox in `plan.md` stays unticked until you approve.

## What shipped

Vite + React + TypeScript + Tailwind v4 + Vitest app under `app/`. Phone chrome only.

- Five bottom tabs: **Home · Ledger · Plan · Wealth · More** (`/home`, `/ledger`, `/plan`, `/wealth`, `/more`). `/` redirects to `/home`.
- Floating **+** on every tab opens a bottom sheet titled Quick Add, body **Quick Add — Phase 12**, Close / overlay / Escape dismisses it.
- Each tab is a placeholder (title + which later phase owns the real screen). No engine, no data.
- Empty folders ready for later phases: `app/src/engine/`, `store/`, `import/`, `dev/`.
- `fixtures/` exists and is gitignored (for real xlsx copies later).
- Dark mode follows the system. Desktop is the same UI, centred at 480px.
- Standalone PWA: `manifest.webmanifest` + PNG icons + a pass-through service worker so Android Chrome/Brave can **Install app** (no browser chrome). Not the Phase 17 install-prompt UI.
