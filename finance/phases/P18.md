## What shipped

- **Wealth overview** (`/wealth`) — net worth hero (no sparkline; that is Phase 22), three bucket cards in priority order with fill rings vs target, tagged accounts, assets vs liabilities lists (tap → Accounts). Investment shows invested cost; current NAV is Phase 22.
- **EF fill uses tagged accounts** — Emergency Fund current is the sum of FD and any other account tagged to that bucket (`bucketCurrentBalances`). Fill % is current / target.
- **Bucket rule editor** (`/wealth/buckets`, gear on Overview) — order (Up/Down), name, active, target rule (months of essentials / fixed ₹ / none), fill mode (until target / % / fixed ₹ / remainder), min monthly (stored; waterfall does not apply it), linked accounts (one account → one bucket), notes. Guardrails: exactly one remainder; % fills ≤ 100.
- **Live example** — “With ₹… surplus today this plan gives EF ₹…, Savings ₹…, Investment ₹…”. Surplus is today’s free-to-allocate (same engine number as Home). Editing Savings 10k → 30k updates the rings and that split immediately; **Save rules** persists to SQLite and does **not** post ledger rows.

Allocate confirm is still Phase 19 (disabled CTA on Overview when free > 0). Goals / Invest / Portfolio stay later.
