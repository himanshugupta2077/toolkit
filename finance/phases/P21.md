## What shipped

- **Invest page** (`/wealth/invest`) — one scroll: SIP/dip sliders (sum 100), this month’s SIP list, assets, theme engine, dip reserve, “AI research (coming)”.
- **Plan editor** — assets have %, kind (core/theme), dip priority, active, instrument note. Add / remove / Up-Down dip order. Live “sum = 100% ✓” and **Normalise**. Turning an asset off (Gold) re-normalises remaining weights and the SIP rupees.
- **Save version** — `PUT /api/invest/plan` inserts a **new** row (`effective_from=today`, new asset ids). Previous versions stay so old allocation runs keep the old split. Import/seed still replace.
- **Theme engine** — edit the ₹20,000 threshold and which themes sit in each tier. The active tier is labelled for the what-if amount.
- **This month’s SIP** — last confirmed Investment allocation amount, or type a what-if. Same `splitInvest` math as Phase 8. Allocate’s preview now links here.
- **Dip reserve** — virtual pool. Confirming an allocation with Investment > 0 credits `dip_reserve_ledger`. **Deploy** sheet: amount, suggested split by dip priority (editable), From → To → Investment ledger rows. Holdings/NAV are Phase 22, so this phase is ledger-only.

Approval cases:

- Gold off → remaining % sum to 100% and Gold is out of the SIP list.
- Amount ₹10,000 → Automation & Robotics SIP ₹0; ₹25,000 → themes on.
- Deploy dip ₹N → reserve down by N, ledger Investment rows sum to N.
