# Phase 12 — Quick Add (approved)

Implemented 2026-09-06. Approved 2026-09-06 (₹50 Personal care logged from the sheet).

## What shipped

The floating **+** is a real capture sheet. It writes one Ledger row through `POST /api/ledger` into SQLite on the laptop. Product tabs besides this sheet stay placeholders (Ledger list is Phase 13, Home is Phase 15).

- **Type pills** — Expense · Income · Transfer · CC pay · Refund · Invest, with Adjustment under **More**.
- **Amount keypad** — rupees, `.` for paise, `+` to sum (`120+80`). No OS keyboard for the amount.
- **From → To** — defaults per type. Expense hides the virtual Expense account and shows category instead. Refund hides Expense as From. Tapping a chip opens a picker (valid accounts only, recent first).
- **Category chips** — recent (or first eight) + **All** grouped list. Picking a category sets **In budget** to that category’s default. Toggle explainer uses this month’s cap.
- **Date** — Today / Yesterday / Pick. **Note** placeholder is the last note in that category.
- **Save** / **Save & add another** — optimistic toast, then `POST /api/ledger`. On failure the toast becomes **not saved** and the optimistic row is rolled back. Illegal From/To is an inline hint and Save stays disabled (not a silent save).
- After save, `/dev/store` this-month **budget spent** updates (Home does not exist yet). Clearing site data does not delete the row.

Out of scope as planned: natural-language parse, link-to-goal/plan, holding units/NAV.
